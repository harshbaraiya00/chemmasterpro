## Structures and mechanism scope

The new data includes 226 locally rendered SMILES depictions plus precise inline Fischer, Haworth and Newman diagrams. Some SMILES deliberately describe connectivity only, with explicit captions when stereochemistry is unspecified. Fischer/Haworth configurations are drawn explicitly rather than inferred from such connectivity views. Polymer, glycosidic, protein and nucleotide visual summaries are labelled connectivity/process schematics.

Existing complete mechanism sheets are reused only where applicable. Reasoning lists are not claimed to be elementary electron-pushing mechanisms. An alkyne-hydroboration extension is explicitly distinguished from direct textbook content, with its additional academic source attached. Nucleobase identities were cross-checked against RCSB component records (ADE, GUN, CYT, TDR, URA); each record's displayed tautomer is a structural representation, not an assertion that only one tautomer exists.
